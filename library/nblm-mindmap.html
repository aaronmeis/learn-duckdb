  • DuckDB Mastery
    • Core Concepts
      • In-Process OLAP
        • Embedded in host process
        • No client-server protocol overhead
        • Zero external dependencies
      • Storage & Data Access
        • Single database file or in-memory
        • Columnar storage layout
        • Direct query of Parquet, CSV, JSON
        • Replacement scans on DataFrames
      • Workload Focus
        • OLAP vs OLTP
        • Large scans and aggregations
    • Engine Architecture & Mental Models
      • Vectorized Execution
        • Processes DataChunks of 2048 rows
        • CPU L1/L2 cache resident processing
        • Optimized branch prediction
        • Vector Formats: Flat, Constant, Dictionary, Sequence
      • Morsel-Driven Parallelism
        • Parallel execution across CPU cores
        • Pipeline separation by blocking operators
        • Dynamic task scheduling without skew traps
      • Query Engine Features
        • Push-based execution engine
        • Out-of-core capabilities (RAM spilling)
        • Subquery unnesting and logical rewrites
        • EXPLAIN plan inspection
    • Ecosystem & Tooling
      • Client APIs
        • Python (Pandas, Arrow, Polars)
        • C, C++, Java JDBC, Node.js
        • R, Rust, WebAssembly (Wasm)
        • CLI and SQL Editors
      • Extensibility
        • Dynamic extension loading
        • httpfs for S3/remote files
        • Postgres/SQLite scanners
        • Spatial, JSON, ICU, DuckLake
      • Engine Comparison
        • vs SQLite: OLAP vs OLTP
        • vs Postgres: In-process vs Client-Server
        • vs Spark/Polars: Local SQL vs Distributed/DataFrame
    • Edge Cases, Traps & Concurrency
      • Concurrency Control
        • Single writer process limit
        • Multiple reader processes in READ_ONLY mode
        • Bulk MVCC and Optimistic Concurrency Control
        • Write transaction conflict errors
      • Resource & Data Traps
        • Memory explosion on bad join explosion
        • Network/NAS file locking issues
        • Timestamp and typecasting quirks
        • Extension trust boundaries
