Cheatsheet — DuckDB

One-page decision card for the DuckDB study day.

Choose When
DuckDB The working set fits one machine and the question is a scan, join, or aggregate. [S1]
SQLite or Postgres Many small writes, many writers, or the file is the system of record. [S3][S4]
Polars You want a dataframe API and you do not need a SQL catalog.
Spark The data will not fit one machine.
MotherDuck You have approved a cloud warehouse. ATTACH 'md:' is that approval's boundary. [S8]
Trap Tell Fix
Second writer Database locked One writer process. Other processes use READ_ONLY. [S3]
Huge join Process dies Build the hash table on the small side. Read EXPLAIN. [S2]
Network file Stall or corruption Keep the writer on a local disk. [S3]
Extension fetch Traffic to extensions.duckdb.org Disable auto-install and auto-load. [S10]
Closed lab ATTACH 'md:' Do not attach MotherDuck. Local DuckDB is not a classified authorization. [S8][S11]
