Quiz bank — DuckDB

Quiz bank mirrored on the Learn DuckDB console.

# Section Question Answer Source
1 Placement Which quadrant does DuckDB claim? In-process OLAP. SQLite is in-process OLTP. A warehouse is client-server OLAP. [S4]
2 Engine What is the default vector size? 2048 tuples in a DataChunk. Operators run on that batch. [S2]
3 Engine Why does a column store help a SUM? It reads the summed column and skips the others. [S2]
4 Engine What problem do morsels avoid? A fixed hash split that leaves threads idle when one key is huge. [S5]
5 Limits When may other processes open the same file? Only to read, and only in read-only mode. [S3]
6 Limits What does ATTACH md: do? It connects this process to MotherDuck. Hybrid execution can run part of the query in their cloud. [S8][S9]
7 Limits Is local DuckDB an authorization for classified data? No. A lab still approves the binary, the extensions, and the machine. No paper here evaluates DuckDB in a classified lab. [S11][S12]
8 Engine Which side should a hash join build? The smaller side. The large side probes. [S2]
9 Trust What does auto-install do? It downloads an extension from extensions.duckdb.org. Turn it off in a closed room. [S10]
10 Placement When is Spark the better tool? When the working set will not fit one machine. [S13]
11 Engine What does a sequence vector store? A start and a step, not every value. [S2]
12 Limits What happens when two threads in the writer update the same row? The later commit fails with a transaction conflict. Appends do not conflict. [S3]
13 Limits What is the difference between INSTALL and LOAD? INSTALL fetches the extension. LOAD activates it. [S10]
14 Engine Do extensions run in a separate process? No. They run inside the host process. [S10]
15 Engine What does EXPLAIN ANALYZE add? It runs the query and prints actual time and row counts. [S1]
16 Engine What is GROUP BY ALL? It groups by every selected column that is not aggregated. [S1]
17 Limits What does opening :memory: do? A database with no file. It ends when the connection closes. [S1]
18 Warrants What warrant makes a local binary a closed-lab proposal rather than an authorization? No ATTACH 'md:' and no auto-install means no MotherDuck session. A lab still approves the binary. Nearby TEE papers do not evaluate DuckDB. [S8][S11]
19 Warrants Why is a slide's 10× or 157 ms not a contract? Those numbers describe a demo. The causal warrant for speed is vectorized columnar scans on your files, which you time. [S2][S5]
20 Warrants What designed test would weaken both "local means no network" and "MotherDuck is the only leak"? First httpfs query with auto-install on; capture a fetch to extensions.duckdb.org. [S10]
